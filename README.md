# 📜 Random Quote Generator

A fully‑featured Random Quote Generator built with **React + Vite** and deployed via **Streamlit Community Cloud**.

## ✨ Features

| Feature | Details |
|---|---|
| Random Quote Display | Shows a random quote on load; avoids immediate repeats |
| New Quote Button | Click to fetch another random quote from the active pool |
| Category Filter | Filter by Motivation / Success / Technology / Life / Education |
| Live Search | Searches quote text and author in real‑time |
| Favourites | Add/remove favourites; persisted in `localStorage` |
| Responsive UI | Works on mobile, tablet, and desktop |

## 🚀 Local Setup

### Prerequisites
- Node.js ≥ 18
- Python ≥ 3.9

### Steps

```bash
# 1. Install Node dependencies
npm install

# 2. Build the React app
npm run build

# 3. Install Python dependency
pip install -r requirements.txt

# 4. Run the Streamlit app
streamlit run app.py
```

Open `http://localhost:8501` in your browser.

### Development Mode (React only)

```bash
npm run dev   # Starts Vite dev server at http://localhost:5173
```

## ☁️ Deploy to Streamlit Community Cloud

1. Push this repository to GitHub.
2. Go to [share.streamlit.io](https://share.streamlit.io) and sign in.
3. Click **New app**, select your repo and branch.
4. Set **Main file path** → `app.py`.
5. Click **Deploy**.

> **Important:** Streamlit Community Cloud does **not** run `npm run build` automatically.  
> Commit the `dist/` folder to the repository before deploying, **or** add a build step:
>
> Create `.streamlit/packages.txt` with `nodejs` and add a `setup.sh` pre‑deploy script that runs `npm install && npm run build`.
